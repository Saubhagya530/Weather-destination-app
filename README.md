# 🌤️ Weather Destination App

This project allows users to check real-time weather conditions in different destinations using a weather API. It fetches live weather data such as temperature, humidity, wind speed, and weather descriptions, and presents it in a user-friendly format.

## 🌍 Features

- Search weather by city or destination name
- Real-time data from a public Weather API (e.g., OpenWeatherMap)
- Displays temperature, conditions, humidity, and wind
- Clean and responsive user interface

## 🔧 Technologies Used

- JavaScript 
- HTML & CSS (if web-based)
- Weather API (e.g., OpenWeatherMap)
